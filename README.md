# Auto_User_Creator
In this script we can creat user with passwd or account comment also

# How to RUN
only root user and user with sudo access can run this script
With the run command provide atleast one argument as a name of user 
If we provide the multiple argument then first one is user name and other is account comment

# Password change
The script provide random password for the new created user
So when user try to login in first time it force to change the passwd so user can set their own passwd
